Lasair VRAs Docs¶

Caution

It’s early days for LSST and this work so these pages are only in their infancy.

What is this?¶

Welcome to the Lasair Virtual Research Assistant website. If you are using (or interested in using) the Lasair Virtual Research Assistants LSST filters and want more information, you’re in the right place!

Redirects¶

1. If you are interested in the Lasair documentation go to the `Lasair Docs <https://lasair.readthedocs.io/en/main/ >`_

  1. These are static pages so if you want to raise an issue or ask a question please go to the Lasair VRA github `discussion board <https://github.com/orgs/LasairVRAs/discussions >`_
